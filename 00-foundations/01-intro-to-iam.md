# IAM: Users & Groups
### Identity and Access Management, -Gloabal Service
- root account create by default, shouldn't be used or shared
- Users are people within your organization, and can be grouped
- Groups only contain users, not groups
- Users don't have to belong to a group, and users can belong to multiple groups

## Permissions
- Users or Groups can be assigned JSON documents called policies
- These policies define the permissions of the users
- In AWS you apply the least privilege principle: don't give more permissions than a user needs

## Creating a New User
- Enter IAM
- Click Users
- Click Create User
- Enter name
- Click access to console
- create IAM user
- if this user is you create custom password otherwise leave autogenerated checked
- Assign User to Group

## Creating a Group
- Enter Name
- Assign Permissions to Group
- Assign User to Group

## Roles
- Roles are similar to Users but are used for system-to-system permissions

## Important Concepts
- IAM Credentials Report lists all your account's users and the status of their various credentials. The other IAM Security Tool is IAM Last Access. It shows the service permissions granted to a user and when those services were last accessed.
