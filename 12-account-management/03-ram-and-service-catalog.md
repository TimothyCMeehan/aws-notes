# AWS Resource Access Manager (AWS RAM)
- Share AWS resources that you own with other AWS accounts
- Share with any account or within your organization
- Avoid resource duplication
## AWS Service Catalog
- Users that are new to AWS have too many options, and may create stacks that are not complliant / in line with the rest of the organization
- Sone users just want a quick self-service portal to launch a set of authorized products pre-defined by admins
- Includes: virtual machines, databases, storage options, etc...
- Service Catalog allows Admin to create CloudFormation templates called Products that together are called a Protfolio which can be controlled by IAM Permissions
